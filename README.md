# Online Doctor Appointment Booking System

A web-based Doctor Appointment Booking System developed using HTML, CSS, JavaScript, FastAPI, and MySQL.

## Features

- Patient Registration
- Patient Login
- Doctor Details
- Book Doctor Appointments
- View Appointments
- Health Reports
- Appointment Status

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- MySQL
